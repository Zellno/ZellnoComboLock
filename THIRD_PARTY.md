# Third-party notice

Zellno Combo Lock does not include third-party source code, models, textures,
sounds, interfaces or compiled packages.

The addon derives its item configuration from the DayZ vanilla
`CombinationLock4` class at runtime. DayZ and its assets remain the property of
Bohemia Interactive a.s. No DayZ asset is redistributed in this repository.

Code Lock, ZenComboLocks and DayZ Expansion are not dependencies and no
resources from those projects are included. Public implementations were used
only to audit general interaction patterns; this repository contains an
independent implementation.
